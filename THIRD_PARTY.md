# Third-party resources and attribution

The MIT license covers this project's original code and original documentation.
It does not relicense datasets, pretrained model weights, quoted dataset text,
paper PDFs, or third-party software. References describe ideas and resources;
their inclusion does not claim authorship of those resources.

| Resource | Use | Original source / terms |
|---|---|---|
| BEIR | Dataset format and official download locations | [Official repository](https://github.com/beir-cellar/beir); follow each underlying dataset's terms |
| SciFact | Corpus, queries, relevance judgments | [AllenAI SciFact](https://github.com/allenai/scifact); [BEIR mirror](https://huggingface.co/datasets/BeIR/scifact) |
| NFCorpus | Corpus, queries, relevance judgments | [Dataset homepage](https://www.cl.uni-heidelberg.de/statnlpgroup/nfcorpus/) |
| FiQA | Corpus, queries, relevance judgments | [Dataset homepage](https://sites.google.com/view/fiqa/) |
| E5-base-v2 | Frozen 768d text encoder | [Model card and license](https://huggingface.co/intfloat/e5-base-v2) |
| NumPy / PyTorch / Sentence Transformers / FAISS | Standard numeric, model and index libraries | Each dependency retains its own license; installed versions are recorded in uv.lock |
| scikit-learn | Independent verification in development tools | [Project](https://github.com/scikit-learn/scikit-learn) |
| RAE and related papers | Referenced algorithms and research context | See README and research notes; RAE/QRAE are not implemented yet |

Original corpora, pretrained models and course PDFs are excluded from the Git
repository. Result tables and numeric audit artifacts are generated by this
project. Short query/title examples in diagnostic artifacts remain attributable
to the underlying dataset; the project's MIT license does not override their
original terms. Download datasets from the linked sources for reproduction.

The PCA, random projection, AE training loop, metrics and experiment orchestration
were implemented independently using standard libraries. No RAE training code
was copied into this project's implementation.
